# LUCA-AI v0.6.0: CLI para agentes

O repositório passa a oferecer `luca`, um CLI Node sem dependências adicionais, com 114 comandos e cobertura das 93 rotas HTTP atuais. Ajuda e descoberta JSON funcionam offline.

Inclui perfis/autenticação, missões, agentes, agenda, equipes/deliberações com espera retomável, chats/anexos/compartilhamento, templates, administração, SOMPO e laboratório. As operações locais reutilizam a lógica de simulação, replay CSV, geofencing, física MEMS e estado de olhos. Exportação HTML de laboratório e serialização de amostras são compartilhadas com o painel.

Contrato para automação: JSON em stdout, erros estruturados em stderr, códigos de saída documentados, stdin/arquivos, downloads, dry-run, timeout e observação NDJSON limitada. Mutações não são repetidas automaticamente; Bearer de máquina continua restrito a deliberações.

Guia: [CLI](../cli.md). Lista gerada: [referência](../cli-reference.md). Inventário/decisões: [plano](../cli-plan.md).

Validação: testes do processo CLI com HTTP controlado e runtime local isolado, comparação do catálogo com as rotas Express, suíte completa do repositório, typecheck e build. Câmera, áudio, inferência MediaPipe e renderização 3D continuam no navegador; não foram validados como dispositivos físicos por este trabalho.
