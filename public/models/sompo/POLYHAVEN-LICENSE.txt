Downloaded from Poly Haven's official asset API on 2026-09-18, with source
MD5 verification. These are original CC0 models and textures, NOT the website's
preview photographs. Runtime derivatives are generated by
scripts/sompo/prepare-polyhaven.py using Blender.

Adaptations: local origin and ground alignment; woody geometry simplification;
photographed leaf mesh islands replaced by UV-fitted leaf cards retaining
their authored position/orientation in the 3D crown; distant canopy thinning
with coverage compensation; Bermuda shoots assembled into ground-cover clumps.
The tree is not a camera-facing photograph or whole-tree billboard.

Runtime GLBs contain geometry and references to content-addressed external
textures. The adjacent .textures.json manifest is required by the CSP-safe
loader. Albedo files are copied from the original source without grading.
Separate alpha maps are used only when the source albedo does not already
contain alpha, avoiding multiplication of the same coverage twice.

source provenance and original file checksums: polyhaven-sources.json.
